## In My Own Words

**What is the cybersecurity landscape, and why does it matter?**

```
They cybersecurity landscape is the systems, people, and data you're protecting. The landscape includes 4 parts that are constantly interacting: attackers, defenders, everyday users, and the infrastructure. This matters because the landscape will always need defending and the 4 parts are always interacting. Attackers are constantly figuring out new ways to get unauthorized access to systems, data, and people. Defenders will always have to protect against the attackers and stay up to date on cyber news and hacker methods/tools. The infrastructure will need updates and patches to keep up against attacks. Everyday users will need to help protect end point devices and prevent attacks as well.
```

**How do hardware, OS, and software layers interact?**

```
The software is clicked on by a user and the specific application talks to the OS and request CPU time. The OS makes a copy of the application from the storage to the RAM. The CPU processes the instructions from the app. The software interface appears on the monitor. If any edits are made in the software and it's saved, the data is saved on the storage hard drive. When a computer is turned on the firmware gets the hardware ready and the OS is loaded into RAM. The OS interface appears on the monitor and the user can interact with the software applications.
```

**One term I want to remember from this week, and why:**

```
One term I want to remember from this week is "motherboard" because I never really think about that piece of hardware. Without the motherboard, none of the other pieces of hardware (BIOS, CPU, RAM, SSD, NIC, etc.) would function.
```
