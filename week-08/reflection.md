1. How are encryption and hashing different?

```text
Encryption and hashing are different because one is for confidentiality and the other is for integrity. Encrypting a file means that it is no longer readable because the data is now in ciphertext. Hashing a file gives the data a unique value, like a fingerprint, that lets you know if the data was changed in anyway.
```

2. How are symmetric and asymmetric cryptography different?

```text
Symmetric and asymmetric cryptography differ because the former uses one key while the latter uses two keys. A symmetric encryption uses the same key to encrypt and decrypt the data. An asymmetric key has a public and private key. The public key is shared with the entities that need it, but the public key stays with the owner. With asymmetric encryption, the same key cannot be used to encrypt and decrypt the file.
```

3. Why does a private key need stronger protection than a public key?

```text
A private key needs stronger protection than a public key because a private key provides authenticity. The private key is proof of identity and must be kept a secret. The public key doesn't need as much protection because it's expected to be shared and can only be used to encrypt or verify.
```
